# 🍎 AI-Based 9-Class Fruit Classification System

An AI-powered image classification project developed using Google Teachable Machine and TensorFlow.js to identify nine different types of fruits.

## 🚀 Live Demo

**[Click Here to Try the Project](https://thorveakshara-create.github.io/fruit-classfier-teachable-machine/)**

## 📌 Project Overview

This project uses a machine learning image classification model trained to recognize nine fruit categories.

Users can upload an image of a fruit, and the model predicts its category along with the prediction confidence percentage.

## 🍓 Supported Fruit Categories

- Apple
- Banana
- Cherry
- Mango
- Kiwi
- Orange
- Strawberry
- Grapes
- Chickoo

## 🛠️ Technologies Used

- Google Teachable Machine – Model training
- TensorFlow.js – Machine learning model integration
- HTML – Webpage structure
- CSS – Website styling
- JavaScript – Prediction functionality
- GitHub – Version control and source code hosting
- GitHub Pages – Website deployment

## ✨ Key Features

- Classification of nine fruit categories
- Image upload functionality
- AI-powered fruit prediction
- Prediction confidence percentage
- Interactive user interface
- Browser-based predictions

## 🧠 Model Training

The image classification model was trained using Google Teachable Machine with nine different fruit classes.

## 🧪 Testing

The application was tested with sample images from the following categories:

| Fruit | Result |
|---|---|
| Banana | Correct |

## ▶️ How to Use

1. Open the live application.
2. Upload an image of any supported fruit.
3. Click the Predict Fruit button.
4. View the predicted fruit category and confidence percentage.
